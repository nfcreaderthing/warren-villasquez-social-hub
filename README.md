# Warren Villasquez - Social Hub

A responsive, single-page social hub with a dark editorial look, acid-lime accents, portrait-led layout, and lightweight motion. Built with plain HTML, CSS, and JavaScript; no package install or build step is needed.

## Preview locally

1. Clone or download this repository.
2. Open `index.html` in a browser, or run `python3 -m http.server 8000` from the project folder.
3. Visit `http://localhost:8000`.

## Files

- `index.html` - page, styling, and motion effects
- `warren.jpg` - supplied profile portrait

## Privacy

This repository was created as private. The page includes contact details supplied for Warren; review them before making the repository public or publishing the page. No hosting or public deployment has been enabled.
